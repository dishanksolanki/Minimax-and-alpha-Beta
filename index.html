Understanding the Intelligence

What is Minimax?

A decision-making algorithm for two-player games. It assumes both players play their best and picks the move with the best guaranteed result.

What is MAX?

The player (the AI) that tries to maximize the evaluation score.

What is MIN?

The player (the human) that tries to minimize the evaluation score.

What is Alpha?

The best value MAX can guarantee so far along the current path.

What is Beta?

The best value MIN can guarantee so far along the current path.

What is Alpha-Beta Pruning?

An optimization that stops exploring a branch once it can no longer change the final decision. It gives the same answer as Minimax with less work.

Pruning condition

alpha >= beta

Time complexity

Plain Minimax: O(b^d). Alpha-Beta in the best case with favorable move ordering: O(b^(d/2)). The real number of nodes explored depends on the board position and move ordering.
